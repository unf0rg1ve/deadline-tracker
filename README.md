# Deadline Tracker

**Веб-система для управления учебными заданиями и дедлайнами**

Приложение помогает студентам, преподавателям и администраторам эффективно планировать, отслеживать и сдавать учебные задания.

---

## Основные возможности

- **Три роли пользователей**: Студент, Преподаватель, Администратор
- Создание, редактирование и удаление заданий
- Цветовая индикация дедлайнов (просрочено / срочно / в норме)
- Загрузка файлов преподавателем и отчётов студентами
- Живой поиск заданий (AJAX)
- Интеграция искусственного интеллекта **Google Gemini** (анализ сложности и времени выполнения задания)
- Разделение заданий по группам и дисциплинам
- Адаптивный дизайн (работает на компьютере и телефоне)

---

## Технологии

- **Backend**: PHP 8 + PDO
- **База данных**: MySQL
- **Frontend**: HTML5, CSS3, JavaScript (Fetch API)
- **ИИ**: Google Gemini API
- **Сервер**: OpenServer (локально) / InfinityFree (продакшн)
